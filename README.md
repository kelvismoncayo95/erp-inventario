# ERP Inventario

Sistema de gestión de inventario y ventas (mini-ERP).

## 📋 Estado actual

- ✅ Base de datos PostgreSQL (`erp_inventario`)
- ✅ 8 tablas con relaciones
- ✅ Modelos SQLAlchemy
- ✅ Schemas Pydantic (validación)
- ✅ API REST de Productos (CRUD completo)
- ✅ Swagger funcionando

## 🛠️ Tecnologías

- **Backend:** FastAPI + SQLAlchemy
- **Base de datos:** PostgreSQL 17 (en Windows)
- **Validación:** Pydantic v2
- **Cliente de prueba:** Swagger UI
